Get your GitHub token

The token lets this page build apps on your own free GitHub account. Takes about 2 minutes.

  1. Have a GitHub account. No account? Sign up free at github.com/signup, then sign in.
  2. Open the token page with the button below. It must be a Classic token (the page title says "New personal access token (classic)"). The name and the two permissions (repo and workflow) are already ticked for you. Do not use Fine-grained tokens.
  3. Under Expiration, pick No expiration (or a long period, you'll need a new token when it ends).
  4. Scroll to the bottom and tap Generate token.
  5. Copy the token (it starts with ghp_). GitHub shows it only once, so copy it right away.
  6. Come back here, open Setup, paste it in Access token, then tap Save & test connection and Create builder repo.
